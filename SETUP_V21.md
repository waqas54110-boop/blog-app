# V21: Group invite links

1. Neon SQL Editor mein `migration_v21.sql` run karo (har group ko invite_token mil jata hai).
2. Deploy karo.
3. Kisi group page ke sidebar mein **🔗 Invite friends** box: Copy, WhatsApp, Facebook, Telegram, Share.
4. Link `/groups/join/<token>` kholne par invite page aata hai; login ke baad "Join group" se member ban jata hai.
5. Owner / admin **Reset invite link** se purana link band kar sakta hai.
